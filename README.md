# OpenKoda

O OpenKoda é um aplicativo desktop para avaliações de segurança autorizadas. A interface usa Tauri, com persistência local em Rust e SQLite.

Consulte as [instruções de desenvolvimento e testes](OpenKoda/app/README.md), o [planejamento do aplicativo](OpenKoda/planejamento/README.md) e o [andamento da implementação](OpenKoda/app/IMPLEMENTACAO.md).

Os instaladores locais sem assinatura são gerados a partir de `OpenKoda/app` pelo [script de empacotamento para Windows](OpenKoda/app/scripts/package-windows.ps1).
