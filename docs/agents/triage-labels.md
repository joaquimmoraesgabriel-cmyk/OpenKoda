# Rótulos de triagem

| Papel canônico | Rótulo GitHub | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Precisa de avaliação |
| needs-info | needs-info | Aguarda informação |
| ready-for-agent | ready-for-agent | Especificado e pronto para execução por agente |
| ready-for-human | ready-for-human | Exige implementação humana |
| wontfix | wontfix | Não será executado |

Quando uma skill citar um desses papéis, use o rótulo correspondente. Preserve rótulos existentes e crie somente os padrões que faltarem.
