# Salvar uma avaliação de um alvo

Em **Avaliações → Nova avaliação → Um alvo**, selecione um projeto ativo. Confira o alvo, preencha o título e o objetivo e clique em **Revisar avaliação**.

- Para guardar o trabalho e revisar o escopo depois, escolha **Salvar rascunho sem revisar escopo**.
- Para registrar o escopo agora, confira os métodos e a janela de tempo, marque a confirmação da revisão e escolha **Salvar avaliação com escopo revisado**. A preparação do plano e a aprovação de operações vêm depois.

## Se a tela informar erro depois de salvar

Mantenha o formulário aberto e clique em **Reenviar a mesma solicitação**. O aplicativo reenvia os dados originais. Se o primeiro envio já tiver gravado a avaliação, o OpenKoda abre esse mesmo registro. Se você já tiver fechado o formulário ou reiniciado o aplicativo, abra as **Avaliações** do projeto e procure o registro antes de iniciar outro pedido.

Se as opções de escopo mudaram desde o envio, **Iniciar outra solicitação com o escopo atualizado** abre uma nova revisão. Use essa opção para registrar uma intenção diferente. Você também pode abrir **Nova avaliação** para criar deliberadamente outro registro com o mesmo título e alvo.
